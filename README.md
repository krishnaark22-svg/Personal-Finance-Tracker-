# Personal Finance Tracker 💰

A full-stack web application to help users track income, expenses, budgets, and savings goals with interactive charts and reports.

---

## 🚀 Features

- 🔐 User Authentication (Login / Register)
- 💵 Income & Expense Tracking
- 🏷️ Category-wise Transactions
- 📊 Interactive Dashboard with Charts
- 📅 Monthly Budget Management
- 🎯 Savings Goals Tracking
- 📈 Financial Reports (Monthly / Yearly)
- 📤 Export Reports (CSV / PDF - optional)
- 📱 Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS / CSS
- Chart.js / Recharts

### Backend
- Node.js
- Express.js

### Database
- MySQL / PostgreSQL

### Authentication
- JWT (JSON Web Token)
- bcrypt.js
